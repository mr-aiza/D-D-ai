# نسخه ۹ — صفحه خلوت و منوهای کوچک

فقط سه فایل را در ریشه مخزن GitHub قرار بده: `index.html` (جایگزین)، `adventure9.css` و `adventure9.js` (جدید).

صفحه اصلی فقط صحنه، داستان، انتخاب‌ها و اقدام آزاد را نمایش می‌دهد. نوار پایین چهار گزینه دارد: داستان، اقدام وابسته به موقعیت، تاس و منو. برگه قهرمان، تنظیمات، نقشه، مبارزه، موجودی، گفتگو، شخصیت‌ها، قوانین و دفتر وقایع داخل پنل کشویی باز می‌شوند. تمام ماژول‌های قبلی را نگه دار.

Worker و Groq تغییری ندارند. ذخیره ابری D1 و استقرار خودکار Worker طبق برنامه برای مرحله نهایی باقی می‌مانند.
