# Infinite Realms 6 — Cinematic Realm

این بسته **فقط سه فایل** دارد: `index.html` جایگزین می‌شود و `adventure6.css` و `adventure6.js` اضافه می‌شوند. فایل‌های مراحل ۱ تا ۵ و Worker فعلی را حذف یا تغییر ندهید.

قابلیت‌ها: HUD سینمایی، صحنه‌های واکنش‌گرا به متن AI (طوفان/میخانه/جادو/شهر/نبرد)، ذرات نور، قطب‌نما، صفحه ورود سینمایی، حالت تمام‌صفحه، کنترل جلوه‌ها، میانبرهای سریع، پرتاب D20 با انیمیشن، پیشرفت روایی و اعلان صحنه تازه. تنظیمات جلوه‌ها در مرورگر ذخیره می‌شود. تصاویر و افکت‌ها CSS هستند و برای سرعت و موبایل بهینه شده‌اند. با ترجیح Reduce Motion سیستم سازگار است.

نکته: صحنه‌های تصویری این مرحله **بر اساس کلیدواژه‌های روایت** و با CSS تغییر می‌کنند؛ تصویرسازی اختصاصی با AI یا موتور سه‌بعدی نیست. قوانین مبارزه، ذخیره ابری و Worker دست‌نخورده باقی مانده‌اند.

تنظیم D1 و انتشار خودکار Worker طبق درخواست برای مرحله نهایی باقی می‌مانند.
