# رفع مشکل دسترسی به کمپین‌ها و سناریوساز

فایل `index.html` را جایگزین و `navigation11.css` و `navigation11.js` را به ریشه مخزن اضافه کن. سایر فایل‌ها را دست نزن.

دکمه «☰ بخش‌ها» در بالای همه صفحه‌ها ثابت است. از آن می‌توانی سناریوساز، کمپین‌ها، شخصیت‌ها، داشبورد و ادامه بازی را باز کنی. منوی کوچک داخل بازی مستقل باقی می‌ماند. هیچ داده ذخیره‌شده‌ای حذف نمی‌شود.

اگر نسخه ۱۰ را نصب نکرده‌ای، ابتدا نسخه ۱۰ را نصب کن.
