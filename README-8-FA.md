# مرحله ۸ — رابط موبایل و کنترل وابسته به موقعیت

فقط `index.html` را جایگزین و `adventure8.css` و `adventure8.js` را در ریشه مخزن اضافه کنید. فایل‌های مرحله‌های ۱ تا ۷ را حذف نکنید.

در موبایل: صحنه به شکل ستونی نمایش داده می‌شود، اطلاعات قهرمان زیر روایت صحنه قرار می‌گیرد، نوار ثابت پایین ابزارهای ضروری را نشان می‌دهد و امکانات دیگر در پنل کشویی باز می‌شوند. ابزارهای نبرد، گفتگو و سفر با توجه به متن آخرین روایت برجسته می‌شوند. تشخیص موقعیت مبتنی بر کلمات است، نه درک قطعی AI. ذخیره‌سازی و Worker دست‌نخورده باقی می‌مانند.

در پایان پروژه: انتشار خودکار Worker با GitHub Actions، ساخت Cloudflare D1، اجرای schema.sql، شناسه D1 در wrangler.toml و تنظیم CLOUDFLARE_API_TOKEN و CLOUDFLARE_ACCOUNT_ID.
