# Infinite Realms — نسخه اولیه تحت وب

یک نمونه اجرایی آفلاین و راست‌به‌چپ برای طراحی و مدیریت ماجراجویی‌های رومیزی فانتزی با الهام از D&D.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای اجرای محلی با سرور نیز می‌توانید از پوشه پروژه دستور زیر را اجرا کنید:

```bash
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. نیاز به نصب پکیج یا کلید API نیست. فونت Vazirmatn در صورت اتصال به اینترنت بارگذاری می‌شود؛ فونت جایگزین آفلاین در نظر گرفته شده است.

## قابلیت‌های اجرایی

- تولید سناریوی سه‌پرده‌ای با بذر قابل بازتولید، ژانر، محیط، سطح و تعداد بازیکنان
- شاخه‌های مذاکره، نبرد و راه سوم، NPC، دشمن، راز DM، چالش و پاداش پیشنهادی
- ذخیره کمپین، یادداشت DM، خروجی JSON و واردکردن JSON کمپین
- ساخت شخصیت با شش ویژگی اصلی، محاسبه اصلاح‌کننده‌ها و پاداش تسلط
- تاس‌های d4/d6/d8/d10/d12/d20/d100 با Advantage و Disadvantage برای d20
- ردیاب Initiative، راند، نوبت و HP در مبارزه
- ذخیره خودکار در localStorage مرورگر و خروجی پشتیبان JSON

## محدودیت‌های مهم

این نسخه یک MVP سمت مرورگر است؛ موتور هوش مصنوعی، حساب کاربری، دیتابیس سروری، همکاری چندنفره، ویرایش کامل برگه شخصیت، محاسبه خودکار CR، سیستم جامع جادو، محاسبه خودکار مبارزه و PDF هنوز پیاده‌سازی نشده‌اند. تولید سناریو بر پایه ترکیب داده‌های داستانی و بذر است، نه مدل زبانی. قوانین ارائه‌شده صرفاً یک زیرمجموعه برای نمونه اولیه هستند؛ برای اجرای کامل باید نسخه قوانین و محتوای دارای مجوز مشخص شوند. پاک کردن داده‌های سایت در مرورگر ممکن است اطلاعات را حذف کند؛ مرتب از خروجی پشتیبان استفاده کنید.

## فایل‌ها

- `index.html` — صفحات و ساختار رابط
- `style.css` — رابط واکنش‌گرا و تاریک
- `app.js` — موتور سناریو، ذخیره‌سازی، شخصیت، تاس و مبارزه

## مسیر توسعه

1. جداکردن موتور قوانین و مولد سناریو به ماژول‌های مستقل و افزودن تست
2. اتصال FastAPI و PostgreSQL، احراز هویت و مدیریت کمپین چندکاربره
3. موتور قوانین نسخه مشخص D&D و داده‌های SRD مجاز
4. اتصال اختیاری مدل محلی برای روایت پویا و حافظه بلندمدت کمپین
