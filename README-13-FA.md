# Infinite Realms REBORN 13 — نصب

این بسته **فقط فایل‌های تغییرکرده** دارد. فایل `index.html` را در ریشه مخزن جایگزین کنید؛ `reborn13.css` و `reborn13.js` را در ریشه اضافه کنید. سایر فایل‌ها از نسخه ۱۲ باید باقی بمانند. اگر نسخه ۱۲ را نصب نکرده‌اید ابتدا آن را نصب کنید.

صفحه اصلی: هدر ساده، وضعیت قهرمان، صحنه سینمایی، مینی‌مپ موقعیت واقعی ذخیره‌شده، روایت، گزینه‌های داستان، اقدام آزاد و ابزارهای سریع. دکمه طلایی شناور همه ابزارهای قبلی را باز می‌کند؛ دکمه بخش‌ها به سناریوساز، کمپین‌ها و شخصیت‌ها دسترسی می‌دهد. هیچ کلید API در این بسته نیست.

نقشه با رویداد `ir:state-change` و وضعیت `infinite-realms-stage10` به‌روزرسانی می‌شود؛ منظور از زنده، همگام با وضعیت ثبت‌شده بازی است، نه GPS یا حرکت مستقل حدسی. این بسته بازطراحی رابط کاربری است و موتور مبارزه/جادو/آیتم نسخه ۱۰ را جایگزین نمی‌کند. Worker، Groq و D1 تغییر نمی‌کنند.

آزمون پس از انتشار: کمپین جدید بسازید؛ قهرمان جدید بسازید؛ وارد بازی شوید؛ ابزارها را باز کنید؛ سفر تأییدشده انجام دهید و تغییر نشانگر نقشه را بررسی کنید. اگر سایت قدیمی نمایش داده شد، حافظه کش مرورگر را تازه‌سازی کنید؛ localStorage را پاک نکنید.
