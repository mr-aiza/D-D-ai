# Infinite Realms 7 — Rules & Character

فقط `index.html` را جایگزین و `adventure7.js` و `adventure7.css` را در ریشه مخزن اضافه کن. فایل‌های قبلی را حذف نکن.

قابلیت‌ها: HP و جان موقت، AC، آزمون مهارت با برتری/ضعف و DC، تاس نجات مرگ، جایگاه‌های جادو، استراحت کوتاه و بلند، وضعیت‌ها، خستگی، الهام، ثبت وقایع و خروجی JSON. اطلاعات هر کمپین در مرورگر ذخیره می‌شوند.

محدودیت: این ابزار بر اساس مفاهیم رایج D&D 5e ساخته شده و جایگزین موتور کامل قوانین نیست؛ اعمال کلاس‌ها، طلسم‌ها، تمرکز و قوانین خاص کمپین همچنان دستی است. نتیجه آزمون فقط با دکمه اعلام نتیجه در کادر اقدام قرار می‌گیرد و خودکار برای AI ارسال نمی‌شود.

اتصال فعلی Worker بدون تغییر می‌ماند. در مرحله نهایی، GitHub Actions، D1 و Secrets را تنظیم کن.
