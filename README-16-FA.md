# Infinite Realms 16 — Tactical Adventure

این بسته **مکمل نسخه ۱۵** است، نه جایگزین نسخه‌های قبلی. ابتدا نسخه ۱۵ را نصب کنید.

## نصب
سه فایل زیر را در ریشه مخزن قرار دهید:
- `index.html` — جایگزین فایل نسخه ۱۵؛ تنها دو ارجاع به CSS و JS جدید اضافه شده‌اند.
- `adventure16.css` — جدید.
- `adventure16.js` — جدید.

فایل‌های قبلی، Worker و داده‌های localStorage را حذف نکنید. نسخه ۱۵ در GitHub ممکن است هنوز منتشر نشده باشد؛ در این صورت ابتدا فایل‌های بسته نسخه ۱۵ را آپلود کنید.

## قابلیت‌ها
- پنل شناور نبرد و سفر، مستقل از منوی اصلی.
- ثبت راند/نوبت و حمله با d20 امن از `crypto.getRandomValues` و اصلاح‌کننده پایه قدرت + proficiency؛ نتیجه اصابت و آسیب با DM است.
- Dodge، بررسی مهارت، HP، درمان و temp HP با ذخیره روی برگه واقعی قهرمان نسخه ۷/۱۵.
- نقشه فعلی و مقصدهای کشف‌شده از اطلاعات نسخه ۱۰/۱۴؛ فاصله فقط تخمین تصویری است.
- درخواست سفر به AI ارسال می‌شود؛ موقعیت تا زمان تأیید رویداد travel تغییر نمی‌کند.
- لاگ نبرد برای هر قهرمان و کمپین جداگانه در `infinite-realms-tactical16`.

## محدودیت‌ها
- این یک ابزار تاکتیکی و پل اتصال به راوی است، نه موتور خودکار کامل D&D 5e؛ حمله بر اساس قدرت پایه است و سلاح‌های finesse/ranged و مزیت/عدم‌مزیت خودکار محاسبه نمی‌شوند.
- نوبت‌ها فعلاً چرخه ساده بازیکن/حریف دارند؛ چند دشمن و initiative پیشرفته هنوز در موتور قدیمی قرار دارند.
- ذخیره ابری جدید فقط در صورت اضافه شدن کلید `infinite-realms-tactical16` به بسته ابری نسخه ۱۵ ممکن است؛ در این بسته لاگ تاکتیکی فقط محلی است.
- تست نحو JS انجام شده؛ تست واقعی مرورگر و Cloudflare انجام نشده است.
