# Infinite Realms 14 — Core Repair

این بسته فقط دو فایل موجود را جایگزین می‌کند: `game.js` و `adventure10.js`. بقیه فایل‌های نسخه ۱۳ را دست‌نخورده نگه دارید. نسخه ۱۳ باید قبلاً نصب شده باشد.

## اصلاحات
- باگ shadowing در game.js: اکنون وضعیت واقعی قهرمان (موجودی، طلا، مهارت، نقشه و HP) به DM فرستاده می‌شود.
- «کشف مکان» دیگر به معنای «سفر» نیست؛ فقط رویداد `travel` پس از تأیید بازیکن، مکان فعلی را تغییر می‌دهد. برای سفر مقصد باید از قبل کشف شده باشد.
- آیتم و جایگاه جادو قبل از پاسخ DM کم نمی‌شود؛ پیشنهاد مصرف بعد از پاسخ به تأیید بازیکن نیاز دارد. خطای شبکه منبعی مصرف نمی‌کند.
- رویدادهای تأییدنشده در وضعیت کمپین ذخیره می‌شوند؛ منوی بازی گزینه «رویدادهای در انتظار تأیید» دارد.
- ذخیره ابری جدید یک snapshot از داستان و ذخیره‌های RPG مربوط به همان کمپین ارسال می‌کند؛ بازیابی نسخه‌های قدیمی فقط داستان را بازیابی می‌کند. اگر Cloudflare D1 فعال نیست، همچنان ذخیره محلی کار می‌کند.
- خروجی پشتیبان دکمه اصلی، snapshot کامل کمپین را شامل می‌شود.

## محدودیت‌ها
- این نسخه، معماری چند فایل قدیمی را کاملاً به یک موتور جدید تبدیل نمی‌کند؛ یکپارچگی از طریق snapshot و رخدادهای وضعیت بهتر شده است.
- در سیستم مبارزه قدیمی هنوز تمام محاسبات نوبت و دفاع به موتور واحد منتقل نشده است.
- تأیید رویدادهای AI، جایگزین داوری خودکار و قطعی قوانین D&D نیست.
- فایل‌های محلی مرورگر، ذخیره ابری و حساب کاربری واحد نیستند. برای استفاده از Cloudflare D1 باید تنظیمات قبلی برقرار باشد.
- قبل از نصب از ذخیره‌های مرورگر و فایل‌های GitHub پشتیبان بگیرید.
